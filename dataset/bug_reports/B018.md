# Bug Report: B018

- **Category**: boundary
- **Difficulty**: hard
- **Issue Report Quality**: vague
- **Scope**: single-file

## Issue Report

Under certain conditions, the checkout total can become zero even on expensive orders.

## Expected Behavior

Creating a discount with percentage=100 should be rejected with HTTP 400.

## Actual Behavior

A 100% discount is accepted, which can reduce the post-discount price to zero.

## Root Cause

- **File**: app/services/discount_service.py
- **Function**: create_discount
- **Lines**: 8
- **Affected Files**: app/services/discount_service.py

### Description

The validation uses discount_percent > 100 instead of >= 100, allowing exactly 100% through.

## Reproduction Steps

  1. Call create_discount with discount_percent=100.
  2. Observe that the discount is created instead of being rejected with 400.
