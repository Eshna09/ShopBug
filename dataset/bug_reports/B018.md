## Issue Report

> Sometimes items disappear from other users' carts on their own. One user reported
> their cart was cleared even though they hadn't removed anything.

## Expected Behavior

`remove_from_cart(user_id, product_id)` deletes only the cart item where both
`user_id` **and** `product_id` match.

## Actual Behavior

The query filters only by `product_id`, ignoring `user_id`. The first matching row for
that product — which may belong to a different user — is deleted.

## Root Cause Description

`cart_service.py` lines 30–31:
```python
# BUG
item = db.query(CartItem).filter(
    CartItem.product_id == product_id
).first()
# CORRECT
item = db.query(CartItem).filter(
    CartItem.user_id == user_id,
    CartItem.product_id == product_id
).first()
```
`CartItem.user_id == user_id` was removed from the filter. When multiple users have the
same product in their carts, deleting for one user silently removes the other user's item.

## Reproduction Steps

1. Add product P to both User A's and User B's carts.
2. `DELETE /cart/remove/{P}?user_id={B_id}` (User B removes their item).
3. Retrieve User A's cart — observe the item has been removed from User A's cart.
