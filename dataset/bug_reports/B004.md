# Bug Report: B004

- **Category**: boundary
- **Difficulty**: easy
- **Issue Report Quality**: specific
- **Scope**: single-file

## Issue Report

I was able to add a product to my cart with a quantity of 0 and it stayed in the cart.

## Expected Behavior

Adding to cart with quantity=0 should be rejected with HTTP 400.

## Actual Behavior

Quantity=0 is accepted and a cart item with zero quantity is created.

## Root Cause

- **File**: app/services/cart_service.py
- **Function**: add_to_cart
- **Lines**: 9
- **Affected Files**: app/services/cart_service.py

### Description

The quantity validation uses quantity < 0 instead of quantity <= 0, allowing zero-quantity items through.

## Reproduction Steps

  1. Create a product with stock > 0.
  2. Call add_to_cart with quantity=0.
  3. Observe that no error is raised and the item is added.
