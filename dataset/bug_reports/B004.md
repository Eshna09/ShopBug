## Issue Report

> `POST /cart/add` accepts `quantity=0` without returning an error.
> A cart item with zero quantity should not be allowed.

## Expected Behavior

`add_to_cart` rejects `quantity=0` with HTTP 400 and the message
"Quantity must be greater than zero."

## Actual Behavior

`quantity=0` bypasses validation because the guard is `quantity < 0` instead of
`quantity <= 0`. A cart item with zero quantity is created successfully (HTTP 201).

## Root Cause Description

`cart_service.py` line 8:
```python
# BUG
if quantity < 0:
# CORRECT
if quantity <= 0:
```
The strict less-than comparison allows the boundary value of exactly zero through.

## Reproduction Steps

1. Create a product with `stock > 0`.
2. `POST /cart/add` with body `{"user_id": 1, "product_id": 1, "quantity": 0}`.
3. Observe HTTP 201 — item created with `quantity=0` instead of HTTP 400.
