## Issue Report

> The products page loads but never shows any products. The loading spinner disappears
> and then nothing appears — just an empty page.

## Expected Behavior

After `GET /products/` completes successfully, the Products page renders a grid of
product cards.

## Actual Behavior

`loadProducts()` calls `setProducts([])` unconditionally, discarding the API response.
The page always shows the empty-state message regardless of how many products the
backend returns.

## Root Cause Description

`Products.jsx` line 23:
```js
// BUG
setProducts([])
// CORRECT
setProducts(all || [])
```
The variable `all` holds the successful API response, but the state update ignores it
and always resets to an empty array. The page renders as if no products exist.

## Reproduction Steps

1. Ensure at least one product exists in the database.
2. Navigate to `/products`.
3. Observe the loading skeleton disappears and the empty-state ("No products available")
   is shown, even though the backend returned products.
