## Issue Report

> Adding a product to my cart doesn't work. I click Add to Cart and it says
> "Added to cart!" but when I open my cart it's empty. Sometimes I get a
> "product not found" error.

## Expected Behavior

`cartApi.add(user.id, product.id, 1)` creates a cart item linking the authenticated
user to the selected product.

## Actual Behavior

The arguments are swapped: `cartApi.add(product.id, user.id, 1)`. The cart item is
created with `user_id = product.id` and `product_id = user.id`, associating it with
the wrong user and wrong product.

## Root Cause Description

`ProductCard.jsx` line 22:
```js
// BUG
await cartApi.add(product.id, user.id, 1)
// CORRECT
await cartApi.add(user.id, product.id, 1)
```
`cartApi.add` signature is `add(userId, productId, quantity)`. Swapping the first two
arguments stores the cart item under a phantom user ID (the product's numeric ID) so
the authenticated user's cart remains empty.

## Reproduction Steps

1. Log in and navigate to the Products page.
2. Click **Add to Cart** on any product.
3. Navigate to Cart — the cart appears empty.
4. In the database, observe a cart item with `user_id = product.id`.
