# Bug Report: B013

- **Category**: edge_case
- **Difficulty**: medium
- **Issue Report Quality**: specific
- **Scope**: single-file

## Issue Report

A product with 0 items in stock is still showing as available for purchase.

## Expected Behavior

A product with stock=0 should have available=False.

## Actual Behavior

A product with stock=0 has available=True because the check uses stock >= 0 instead of stock > 0.

## Root Cause

- **File**: app/services/product_service.py
- **Function**: create_product
- **Lines**: 18
- **Affected Files**: app/services/product_service.py

### Description

The availability assignment uses data.stock >= 0 instead of data.stock > 0, marking zero-stock products as available.

## Reproduction Steps

  1. Create a product with stock=0.
  2. Check the product's available field.
  3. Observe that available is True instead of False.
