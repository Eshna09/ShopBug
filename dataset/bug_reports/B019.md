# Bug Report: B019

- **Category**: multi_interaction
- **Difficulty**: hard
- **Issue Report Quality**: moderate
- **Scope**: multi-file

## Issue Report

After placing an order, the product stock count doesn't change, allowing the same stock to be bought multiple times.

## Expected Behavior

After checkout, each product's stock should be decremented by the purchased quantity.

## Actual Behavior

Stock is not decremented after checkout, so products remain at their original stock level.

## Root Cause

- **File**: app/services/checkout_service.py
- **Function**: checkout
- **Lines**: 42, 43, 44
- **Affected Files**: app/services/checkout_service.py, app/services/product_service.py

### Description

The stock decrement block (product.stock -= quantity and availability update) was removed from the checkout function.

## Reproduction Steps

  1. Create a product with stock=5.
  2. Add 2 units to cart and checkout.
  3. Observe that product stock is still 5 instead of 3.
