# Bug Report: B016

- **Category**: data_handling
- **Difficulty**: hard
- **Issue Report Quality**: vague
- **Scope**: multi-file

## Issue Report

The order history shows a different amount than what I was charged at checkout.

## Expected Behavior

The order's total_amount should be the final total (subtotal - discount + tax).

## Actual Behavior

The order's total_amount is set to the subtotal only, ignoring discount and tax.

## Root Cause

- **File**: app/services/checkout_service.py
- **Function**: checkout
- **Lines**: 38
- **Affected Files**: app/services/checkout_service.py

### Description

The Order is created with total_amount=subtotal instead of total_amount=total_amount, ignoring the computed discount and tax.

## Reproduction Steps

  1. Create a product priced at $100 with stock.
  2. Add to cart and checkout.
  3. Observe that order.total_amount is 100 (subtotal) instead of 110 (subtotal + tax).
