## Issue Report

> I applied a discount code to my cart but the discount isn't reflected in my order.
> The total at checkout is the same as if I hadn't applied any discount.

## Expected Behavior

When a discount has been applied and the user clicks Checkout, the discount ID is passed
to the checkout API so the order total reflects the discount.

## Actual Behavior

The `discountId` ternary branches are inverted. When a discount **is** applied
(`appliedDiscount` is truthy), `null` is sent — dropping the discount. When no discount
is applied, an ID is sent — adding an unexpected discount.

## Root Cause Description

`Cart.jsx` lines 117–118:
```js
// BUG
const discountId = appliedDiscount
  ? null
  : KNOWN_DISCOUNTS.find((d) => d.code === discountCode.trim().toUpperCase())?.id
// CORRECT
const discountId = appliedDiscount
  ? KNOWN_DISCOUNTS.find((d) => d.code === discountCode.trim().toUpperCase())?.id
  : null
```
The ternary arms are transposed. The truthy branch (discount was applied) should return
the discount ID, not null.

## Reproduction Steps

1. Add items to cart and apply discount code `SAVE10`.
2. Verify the discount amount appears in the order summary.
3. Click Checkout.
4. Inspect the resulting order — the discount is not applied.
