# Bug Report: B020

- **Category**: logic
- **Difficulty**: easy
- **Issue Report Quality**: specific
- **Scope**: single-file

## Issue Report

After registering and logging in with the same password, I get an authentication error.

## Expected Behavior

Registering with a password and then logging in with that same password should succeed.

## Actual Behavior

Login fails because the password is stored as plaintext, so bcrypt verification cannot match the hash format.

## Root Cause

- **File**: app/services/auth_service.py
- **Function**: register_user
- **Lines**: 16
- **Affected Files**: app/services/auth_service.py

### Description

The register_user function stores the password as plaintext (hashed = password) instead of hashing it with bcrypt, so login verification fails.

## Reproduction Steps

  1. Register a user with password 'abc123'.
  2. Attempt login with 'abc123'.
  3. Observe that login fails with an unknown hash error.
