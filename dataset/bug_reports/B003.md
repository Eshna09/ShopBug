# Bug Report: B003

- **Category**: logic
- **Difficulty**: easy
- **Issue Report Quality**: specific
- **Scope**: single-file

## Issue Report

I can log in with the wrong password but cannot log in with the correct password.

## Expected Behavior

Login should succeed only when the provided password matches the stored hash.

## Actual Behavior

Login succeeds with an incorrect password and fails with the correct password.

## Root Cause

- **File**: app/services/auth_service.py
- **Function**: login_user
- **Lines**: 28
- **Affected Files**: app/services/auth_service.py

### Description

The password verification condition is reversed: it raises 401 when verification succeeds and returns the user when verification fails.

## Reproduction Steps

  1. Register a user with password 'correctpass'.
  2. Attempt login with password 'wrongpass'.
  3. Observe that login succeeds instead of returning 401.
