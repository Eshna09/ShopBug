# Bug Report: B011

- **Category**: authentication
- **Difficulty**: easy
- **Issue Report Quality**: specific
- **Scope**: single-file

## Issue Report

I was able to register two accounts with the same email address.

## Expected Behavior

Registering with an email that already exists should return HTTP 400.

## Actual Behavior

Duplicate email registration succeeds, creating a second user with the same email (or raising a database integrity error).

## Root Cause

- **File**: app/services/auth_service.py
- **Function**: register_user
- **Lines**: 10
- **Affected Files**: app/services/auth_service.py

### Description

The duplicate-email existence check was removed before inserting a new user, allowing duplicate registrations to reach the database.

## Reproduction Steps

  1. Register a user with email 'test@test.com'.
  2. Register again with the same email.
  3. Observe that no 400 error is raised (or a database error occurs instead).
