# Bug Report: B009

- **Category**: arithmetic
- **Difficulty**: hard
- **Issue Report Quality**: vague
- **Scope**: multi-file

## Issue Report

The total shown in my cart doesn't seem to match the prices of the items I added.

## Expected Behavior

Cart subtotal should be the sum of (product.price * quantity) for each item.

## Actual Behavior

Cart subtotal uses product.stock instead of product.price, giving completely wrong totals.

## Root Cause

- **File**: app/services/cart_service.py
- **Function**: get_cart_subtotal
- **Lines**: 64
- **Affected Files**: app/services/cart_service.py, app/services/checkout_service.py

### Description

The subtotal calculation multiplies item.product.stock by quantity instead of item.product.price by quantity, using stock count as if it were the price.

## Reproduction Steps

  1. Create a product with price=100 and stock=5.
  2. Add 2 units to cart.
  3. Observe subtotal is 10 (5*2) instead of 200 (100*2).
