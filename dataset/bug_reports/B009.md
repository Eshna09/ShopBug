## Issue Report

> My orders page keeps crashing. I open it and the whole page goes blank with an error.
> It worked before but now it's broken.

## Expected Behavior

The Orders page reads order history from `localStorage`. If orders exist they are
displayed; if not, an empty-state message is shown.

## Actual Behavior

When `localStorage` has no stored orders the fallback `'{}'` parses to a plain JavaScript
object `{}`. React then calls `{}.map(...)` which throws `TypeError: orders.map is not a
function`, crashing the entire page.

## Root Cause Description

`Orders.jsx` line 12:
```js
// BUG
const data = JSON.parse(localStorage.getItem(STORAGE_KEY) || '{}')
// CORRECT
const data = JSON.parse(localStorage.getItem(STORAGE_KEY) || '[]')
```
`JSON.parse('{}')` returns a plain object. Arrays have `.map()`, objects do not.
When the component renders `orders.map(...)` on an object, JavaScript throws a TypeError.

## Reproduction Steps

1. Open the application in a fresh browser session (or clear localStorage).
2. Navigate to `/orders`.
3. Observe the page crashes with `TypeError: orders.map is not a function`.
