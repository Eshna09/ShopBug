# Bug Report: B006

- **Category**: search_filter
- **Difficulty**: medium
- **Issue Report Quality**: moderate
- **Scope**: single-file

## Issue Report

Searching for 'laptop' doesn't return products named 'Laptop' or 'LAPTOP'. The search only works when the case matches exactly.

## Expected Behavior

Product search should be case-insensitive and match substrings.

## Actual Behavior

Search uses exact case-sensitive matching, so 'laptop' does not find 'Laptop'.

## Root Cause

- **File**: app/services/product_service.py
- **Function**: search_products
- **Lines**: 33
- **Affected Files**: app/services/product_service.py

### Description

The search query uses == (exact match) instead of ilike (case-insensitive substring match).

## Reproduction Steps

  1. Create a product named 'Laptop'.
  2. Search for 'laptop' (lowercase).
  3. Observe that no results are returned.
