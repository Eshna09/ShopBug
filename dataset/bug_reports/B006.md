## Issue Report

> The products page isn't showing any of the items I added. I added several products
> through the API but the list comes back empty.

## Expected Behavior

`GET /products/` returns all products with `available=True` (i.e. products that have
stock and are ready to sell).

## Actual Behavior

The SQLAlchemy query filters on `Product.available == False`, so only products that are
marked unavailable are returned. All in-stock products are hidden.

## Root Cause Description

`product_service.py` line 28:
```python
# BUG
return db.query(Product).filter(Product.available == False).all()
# CORRECT
return db.query(Product).filter(Product.available == True).all()
```
The boolean comparison is inverted. Products created with `stock > 0` have `available=True`
and are excluded by this filter.

## Reproduction Steps

1. Create a product via `POST /products/` with `stock=5`.
2. Call `GET /products/`.
3. Observe the response is empty — the newly created product does not appear.
