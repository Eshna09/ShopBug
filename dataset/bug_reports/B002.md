# Bug Report: B002

- **Category**: arithmetic
- **Difficulty**: medium
- **Issue Report Quality**: moderate
- **Scope**: single-file

## Issue Report

The tax amount at checkout seems higher than expected when a discount is applied to the order.

## Expected Behavior

Tax should be calculated on the post-discount subtotal (e.g., 10% of $80 = $8 for a $100 order with 20% discount).

## Actual Behavior

Tax is calculated on the pre-discount subtotal (10% of $100 = $10), resulting in overcharged tax.

## Root Cause

- **File**: app/services/checkout_service.py
- **Function**: checkout
- **Lines**: 29
- **Affected Files**: app/services/checkout_service.py

### Description

The tax_amount is computed as subtotal * TAX_RATE instead of post_discount * TAX_RATE, taxing the original amount rather than the discounted amount.

## Reproduction Steps

  1. Create a product priced at $100 with sufficient stock.
  2. Create a 20% discount.
  3. Add the product to cart and checkout with the discount.
  4. Observe tax_amount is 10.0 instead of 8.0.
