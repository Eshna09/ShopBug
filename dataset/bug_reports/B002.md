## Issue Report

> The checkout API returns a higher tax amount than expected when a discount is applied.
> Tax should be based on the discounted total, not the original price.

## Expected Behavior

Tax is calculated on the post-discount subtotal:
`tax = (subtotal - discount_amount) * TAX_RATE`

For a $100 order with a 20% discount: post-discount = $80, tax = $8.00.

## Actual Behavior

Tax is calculated on the pre-discount subtotal:
`tax = subtotal * TAX_RATE`

For a $100 order with a 20% discount: tax is incorrectly $10.00 instead of $8.00.

## Root Cause Description

`checkout_service.py` line 25: `tax_amount = subtotal * TAX_RATE`.
The variable `post_discount` is computed on the line immediately above but is not used
for the tax calculation. It should be `tax_amount = post_discount * TAX_RATE`.

## Reproduction Steps

1. Create a product priced at $100.00 with sufficient stock.
2. Create a 20% discount code.
3. Add the product to a user's cart.
4. Call `POST /checkout/?user_id=N&discount_id=M`.
5. Inspect `order.tax_amount` — observe $10.00 instead of $8.00.
