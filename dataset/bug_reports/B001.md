# Bug Report: B001

- **Category**: arithmetic
- **Difficulty**: easy
- **Issue Report Quality**: specific
- **Scope**: single-file

## Issue Report

When I apply a 20% discount to an order worth $1000, the final discounted price shown is $200 instead of $800.

## Expected Behavior

Applying a 20% discount to a $1000 order should result in a post-discount price of $800.

## Actual Behavior

The post-discount price is $200, which is the discount amount itself rather than the remaining price.

## Root Cause

- **File**: app/services/discount_service.py
- **Function**: apply_discount
- **Lines**: 25
- **Affected Files**: app/services/discount_service.py

### Description

The apply_discount function returns subtotal * (percent/100) instead of subtotal - discount_amount, computing the discount amount rather than the remaining price.

## Reproduction Steps

  1. Create a discount with 20% percentage and no minimum or cap.
  2. Call apply_discount with subtotal=1000.
  3. Observe the result is 200 instead of 800.
