# Bug Report: B005

- **Category**: input_validation
- **Difficulty**: easy
- **Issue Report Quality**: moderate
- **Scope**: single-file

## Issue Report

I was able to create a product with a negative price through the API.

## Expected Behavior

Product creation with a negative price should be rejected with HTTP 400.

## Actual Behavior

Negative prices are accepted and the product is created with the negative price.

## Root Cause

- **File**: app/services/product_service.py
- **Function**: create_product
- **Lines**: 8
- **Affected Files**: app/services/product_service.py

### Description

The price validation guard was removed, so the price <= 0 check only catches stock < 0, not negative prices.

## Reproduction Steps

  1. Call create_product with price=-10 and stock=1.
  2. Observe that the product is created instead of being rejected.
