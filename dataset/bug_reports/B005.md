## Issue Report

> The website works fine until I click Checkout. The button just spins and nothing
> happens. I've tried clearing my cart and re-adding items but checkout never completes.

## Expected Behavior

Clicking Checkout sends `POST /checkout/?user_id=X&discount_id=Y` with parameters in
the query string. The FastAPI endpoint processes the request and returns an order object.

## Actual Behavior

The frontend sends `user_id` and `discount_id` as a JSON **request body**.
FastAPI reads these as **query parameters** only and never finds them in the body,
returning HTTP 422 Unprocessable Entity on every checkout attempt.

## Root Cause Description

`api.js` `checkoutApi.checkout`:
```js
// BUG
return request('POST', '/checkout/', {
  body: { user_id: userId, discount_id: discountId },
})
// CORRECT
return request('POST', '/checkout/', {
  query: { user_id: userId, discount_id: discountId },
})
```
The `request` helper appends `query` values to the URL as query parameters. Using `body`
sends them as JSON, which FastAPI ignores for Query-annotated parameters.

## Reproduction Steps

1. Log in and add a product to cart.
2. Open the Cart page and click Checkout.
3. Open the browser developer tools Network tab.
4. Observe the request to `/checkout/` has a JSON body instead of query params,
   and the response is HTTP 422.
