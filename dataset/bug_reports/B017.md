# Bug Report: B017

- **Category**: search_filter
- **Difficulty**: medium
- **Issue Report Quality**: specific
- **Scope**: single-file

## Issue Report

When I filter products by category 'Electronics', I see all products EXCEPT Electronics.

## Expected Behavior

Filtering by category should return only products in that category.

## Actual Behavior

The filter returns products NOT in the requested category (inverted condition).

## Root Cause

- **File**: app/services/product_service.py
- **Function**: filter_by_category
- **Lines**: 37
- **Affected Files**: app/services/product_service.py

### Description

The filter uses Product.category != category instead of Product.category == category, returning non-matching products.

## Reproduction Steps

  1. Create one Electronics and one Books product.
  2. Filter by 'Electronics'.
  3. Observe that the Books product is returned instead of the Electronics one.
