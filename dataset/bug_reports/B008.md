# Bug Report: B008

- **Category**: boundary
- **Difficulty**: medium
- **Issue Report Quality**: moderate
- **Scope**: single-file

## Issue Report

A discount with a minimum order amount of $500 doesn't apply when the cart total is exactly $500.

## Expected Behavior

When the subtotal equals the minimum order amount, the discount should be applied (>= not just >).

## Actual Behavior

When subtotal equals the minimum order amount, the discount returns 0 (not applied).

## Root Cause

- **File**: app/services/discount_service.py
- **Function**: calculate_discount_amount
- **Lines**: 19
- **Affected Files**: app/services/discount_service.py

### Description

The minimum order check uses subtotal <= min_order_amount (returns 0) instead of subtotal < min_order_amount, excluding the exact boundary.

## Reproduction Steps

  1. Create a discount with min_order_amount=500 and 10% percent.
  2. Call calculate_discount_amount with subtotal=500.
  3. Observe that the discount amount is 0 instead of 50.
