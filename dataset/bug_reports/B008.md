## Issue Report

> I can add more items to my cart than the product has in stock. The API should reject
> quantities that exceed available stock.

## Expected Behavior

`add_to_cart` returns HTTP 400 when `quantity > product.stock`.

## Actual Behavior

There is no stock-overflow check in `add_to_cart`. Any quantity, including amounts far
exceeding stock, is accepted without error.

## Root Cause Description

The guard:
```python
if quantity > product.stock:
    raise HTTPException(status_code=400, detail="Quantity exceeds available stock.")
```
was removed from `cart_service.add_to_cart`. The same check is present in
`update_cart_item` but is absent from the initial add operation.

## Reproduction Steps

1. Create a product with `stock=3`.
2. `POST /cart/add` with `quantity=100`.
3. Observe HTTP 201 — the item is accepted despite stock being only 3.
