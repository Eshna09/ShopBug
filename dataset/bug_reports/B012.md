## Issue Report

> Checkout crashes with a server error. Sometimes it seems to work but the order never
> shows my actual items.

## Expected Behavior

`checkout_service.checkout` fetches cart items for the specific user and builds an order
from those items, then returns the completed order.

## Actual Behavior

`cart_service.get_cart_items` is called without `user_id`, causing a `TypeError` at
runtime. The checkout endpoint returns HTTP 500.

## Root Cause Description

`checkout_service.py` line 12:
```python
# BUG
items = cart_service.get_cart_items(db)
# CORRECT
items = cart_service.get_cart_items(db, user_id)
```
`get_cart_items` signature is `(db, user_id)` — `user_id` is a required positional
argument. Calling it with only `db` raises `TypeError: get_cart_items() missing 1
required positional argument: 'user_id'`.

## Reproduction Steps

1. Add items to a user's cart.
2. `POST /checkout/?user_id=N`.
3. Observe HTTP 500 with `TypeError` in the server log.
